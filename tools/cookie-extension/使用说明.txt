鬼打架 · 淘宝 Cookie 导出 v1.2.0（Mac / Windows 通用）

无需 Python、Playwright、Node.js 或项目环境。需要桌面版 Edge / Chrome 130 或更高版本。
这是本地扩展包，首次使用需手动加载一次；之后点击扩展即可导出。

1. 将 ZIP 完整解压到固定文件夹（不要只打开 ZIP 中的文件）。
2. Edge 地址栏打开 edge://extensions，或 Chrome 打开 chrome://extensions。
3. 开启「开发人员模式」，点击「加载解压缩的扩展 / 加载已解压的扩展程序」。
4. 选择解压后包含 manifest.json 的文件夹，同意淘宝 / 天猫 Cookie 读取权限。
5. 在这个浏览器的同一用户配置中登录淘宝，保持淘宝及目标天猫商品页打开。
6. 点击浏览器工具栏「扩展」中的「鬼打架 · 淘宝 Cookie 导出」。
7. 点击「一键导出 Cookie JSON」，保存 taobao-cookie-*.json。
8. 回到鬼打架「设置 → 淘宝账号 → 上传 Cookie 文件」，上传刚保存的 JSON。

扩展仅在点击导出按钮时读取淘宝 / 天猫 Cookie（包含 HttpOnly、分区 Cookie），不自动上传。
同时读取当前窗口已打开淘宝 / 天猫页面、内嵌淘宝登录页的 localStorage；不合并无痕和普通窗口。
导出完成提示会显示 Cookie 总数、分区数、本地存储来源数和读取失败警告。
v1.2 修复仅读取主页面、遗漏内嵌登录页存储的问题。
未读到 login.taobao.com / passport.taobao.com 的存储会提示，但不等于一定未登录。
已关闭页面和已消失 iframe 的存储无法读取；不会自动打开或刷新页面。
不访问其他网站，不连接远程服务器，不读取你的浏览器个人目录。
请使用普通浏览器窗口；无痕窗口的 Cookie 与普通窗口分开，不会自动合并。
Cookie 可能过期或受淘宝设备风控限制，文件导出成功不代表平台认可会话。
该版本不导出 IndexedDB 或浏览器指纹；无法保证跨设备会话不被平台要求验证。
Cookie JSON 等同于登录凭证，上传完成后请妥善保管或删除。

使用完可在浏览器扩展管理页面移除扩展，无需更改系统安全设置。

旧版升级：重新下载解压后，在扩展管理页选择新版文件夹加载，
或替换原文件夹内容后点击扩展卡片的「重新加载」。确认版本为 1.2.0。
新版首次加载需允许读取淘宝 / 天猫页面存储。请重新导出文件，旧 JSON 无法补回缺失数据。
