## 已修复的问题

| 风险 | 发现与验证 | 修复 |
| --- | --- | --- |
| 高：通知配置可用于向内网发起请求（SSRF） | 隔离测试确认普通通知设置原先接受回环、私网、元数据服务地址及带用户名密码的 URL；发送代码没有对应网络边界。未向生产内网发起探测。 | 保存时与发送时双重校验；阻止本机、内网、保留、多播、IPv4 映射与转换地址；检查全部 DNS 结果，并固定实际连接的公网 IP，同时保留正确的 TLS 域名与 Host。禁用代理环境变量和重定向。已保存的旧配置同样受发送时校验约束。 |
| 中：请求体在大小检查前进入 JSON 解析 | 原设置接口对超大请求进入解析流程；导入与 Cookie 上传的原有大小检查也位于解析后。 | ASGI 层在解析前限制实际读取量；声明超限立即拒绝，无 Content-Length 的分块上传也计数；上传总读取时间最多 30 秒。 |
| 中：CSV 公式防护可被前缀绕过 | 隔离测试复现制表符、换行、空格和 BOM 前缀绕过原有公式检测。 | 使用单引号保护可能的公式文本，同时处理原本的单引号，保证系统导出后重新导入能还原原文。兼容旧版保护格式。 |
| 中：SMTP 未明确启用证书校验 | 原代码使用 smtplib 默认 TLS 上下文，没有明确要求校验证书和主机名。 | 统一使用校验证书的默认安全 TLS 上下文；邮件仅允许公网服务器 465/587 加密端口，连接固定到已检查的 IP，证书仍按原域名校验。 |

额外加固：主页面启用 CSP，限制脚本和连接来源，禁止对象插件与被第三方框架嵌入；限制摄像头、麦克风、定位权限。通知测试按账号每分钟最多 10 次；Webhook 总处理最多 20 秒，响应最多 64 KiB，并拒绝压缩响应以避免解压放大。

## 请求边界

- 账户及安全管理请求：8 KiB。
- 普通请求：128 KiB。
- CSV/JSON 导入、Cookie 导入的 HTTP 外层请求：12 MiB；实际导入文件仍保留原有 5 MB 限制，为 JSON 转义保留外层空间。
- 超限返回 413；上传读取超时返回 408。
- 通知 Webhook 仅支持 HTTPS 443；邮件仅支持 TLS 465 或 STARTTLS 587。自建服务需要公网地址及有效证书。
