# 界面提示精简与逻辑回归（2026-10-19）

## 界面调整

沿用现有玻璃质感、苹方字体和浅深主题。删除重复常驻说明，将 Cookie、日价格、日历、采集规则、预测和备份的辅助说明改为按需展开。保留真实错误、显著阻塞、采集结果、必要进度和删除/覆盖/密码丢失等关键提醒；排队原因仍可在每条任务中查看。

## 修复

- 资源请求按页面身份归属，切换商品、筛选和卸载时中止旧请求；旧响应与旧错误不会写入新页面。
- 状态刷新合并请求并记录在途刷新期间的新请求，保存后需要的刷新不会被直接忽略。
- 区分写入失败和写入后刷新失败；写入已完成时提示页面刷新失败，不误导用户重复提交。
- 商品读取失败显示真实错误与重试入口，不误报商品不存在。
- 设置分区直接跟随网址，返回不带分区的网址时恢复默认分区；切换分区时重新初始化表单，避免残留其他分区字段。
- 剪贴板 API 缺失或复制被拒绝时显示可手动复制的恢复命令。
- 一键采集最后一批已结束或剩余任务已取消时，不再用批次间隔延迟后续人工采集；真实下一批仍等待 8 秒。
